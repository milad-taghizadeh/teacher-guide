Backend:
- مسیر backend شامل راه‌اندازی کامل .NET 9 با ساختار چندلایه (Domain، Application، Infrastructure، Api) است.
- اجرای پایگاه داده به PostgreSQL با رشته اتصال پیش‌فرض Host=localhost;Port=5432;Database=teacher_guide;Username=postgres;Password=postgres متکی است.
- برای اعمال مهاجرت‌ها و داده اولیه، اجرای برنامه Api کافی است. مقداردهی اولیه مدیر بر اساس تنظیمات بخش Admin در appsettings.json انجام شده و گذرواژه قبل از ذخیره با الگوریتم bcrypt هش می‌شود.
- برای اجرا در حالت توسعه: وارد پوشه backend/src/TeacherGuide.Api شوید و دستور dotnet run را پس از نصب پیش‌نیازهای SDK 9 اجرا کنید.
- برای تنظیمات ارسال ایمیل، بخش Email در appsettings.json را با اطلاعات SMTP واقعی تکمیل کنید.
- مقدار Jwt:SigningKey را پیش از اجرا به کلید امن و طولانی تغییر دهید.

Frontend:
- مسیر frontend یک پروژه React با Vite و مدیریت بسته pnpm است.
- برای نصب وابستگی‌ها: pnpm install سپس pnpm run dev (پورت 5173).
- آدرس پایه سمت کاربر از متغیر VITE_API_URL در زمان اجرا خوانده می‌شود؛ در صورت نیاز فایل .env ایجاد کنید.
- رابط کاربری راست‌به‌چپ و کاملاً فارسی طراحی شده است و با ساختار API هماهنگ است.
